# TabiFrame AI 1.2

TabiFrame AI 是一个手机优先的旅行 Vlog 策划账本。它帮助个人用户管理多期旅行项目、查看成田风格拍摄清单、手动勾选计划完成记录，并整理可复制给剪映的文字。

> App 不调用相机或相册，不上传、识别、保存或剪辑视频。勾选只代表用户手动记录某个计划组完成，不代表系统核验了真实素材。

当前唯一开发基准是 [`TABIFRAME_AI_PHASE_PLAN_PROTOTYPE_V2.md`](./TABIFRAME_AI_PHASE_PLAN_PROTOTYPE_V2.md)。旧 M1 计划已从仓库删除。

Phase 0–6 已全部执行；其中 Phase 6 按规格完成了资格核对和安全降级，但因为远程网站授权资格与真实线上推理尚未具备，没有伪造为“站内 AI 已接通”。逐阶段记录见 [`docs/PHASE_COMPLETION.md`](./docs/PHASE_COMPLETION.md)。

## 当前能力

- 多项目首页；内置历史成田篇和“明天沿着港未来线溜达”计划。
- 可按项目、地点、标签、路线步骤和镜头查询，并按旅行状态、完成度筛选及多种方式排序。
- 项目支持“计划中 / 已走过”、标签、旅行回顾、路线步骤和镜头内容/顺序编排，以及带确认的删除。
- 拍摄页支持可选路线地图：用 OpenStreetMap 底图标出编号地点和对应路线步骤，不绘制地点连线；没有地图数据的项目照常使用。
- 成田 38 组、67 条计划素材、5 张参考图及署名完整保留，并调整为 5 个步骤各 1 张；港未来线也为每个步骤补齐 1 张可靠署名参考图。
- 项目和 Checkbox 进度保存到私有 Site 登录身份对应的 D1 数据；同一账户可跨手机和电脑同步，Dexie/IndexedDB 作为本机缓存和旧数据迁移来源。
- 单个 Checkbox 使用远程原子更新，降低两台设备交替勾选时互相覆盖的风险；项目资料编辑使用更新时间冲突保护。
- 同时统计完成组数和对应计划素材条数。
- 最小旅行条件表单，生成可复制的结构化计划指令。
- 不依赖 AI/JSON 的空白旅行记录快速创建，适合补录已经走过的旅程；编排页可新增/删除步骤、镜头和可靠的 HTTPS 参考图链接。
- 外部 ChatGPT/Codex 生成 JSON 后严格校验并导入，不需要 API Key。
- 完整项目 JSON 备份与恢复；ID 冲突时自动创建独立恢复副本。
- 用户确认的《一个人在日本散步》系列固定剪映提示词，以及基于当前项目和勾选记录的本期附加信息。
- 打印/保存 PDF、远程图片失败降级、360px 手机布局。
- 无效旧记录安全隔离并给出备份/恢复建议；带 `verified` 的导入事实必须同时提供可靠 HTTPS 来源和核实时间。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，推荐 pnpm 10+。

```bash
pnpm install
pnpm db:local
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173/`。应用使用 Hash Router，项目地址形如：

```text
http://127.0.0.1:5173/#/projects/narita-2026-10-10/shooting
```

## 使用流程

1. 在项目首页打开成田篇或港未来线计划，或点击“新建旅行计划”。
2. 填写目的地、日期/季节、拍摄时间和目标成片时长。
3. 新旅行可以复制结构化生成指令，在自己的 ChatGPT/Codex 中生成纯 JSON；已经走过的旅行可以直接“快速创建空白旅行记录”。
4. 使用生成路径时，把 JSON 粘贴或作为文件导入；通过 Zod 校验后保存为新项目。
5. 在项目首页用状态、完成度和排序管理旅行；在“修改与编排”中记录旅行回顾并调整步骤或镜头。
6. 在拍摄页查询/筛选镜头并手动勾选；单个进度先原子保存到远程账户，再更新本机缓存。
7. 查看并复制系列固定剪映提示词与本期附加信息。
8. 定期“导出项目备份”；在项目首页可以恢复 JSON。

## 数据与真实性

- 私有 Site 由平台负责登录；项目和进度按 Sites 提供的稳定用户 ID 隔离并保存在 D1。它不是应用自行搭建的账号密码系统，但同一 ChatGPT 账户在不同设备访问同一 Site 时会读取同一份远程数据。
- 浏览器 IndexedDB 仅作缓存。首次升级时会把当前浏览器中的旧项目上传一次；项目首页提供“立即同步”，拍摄页重新获得焦点时会刷新远程进度。
- JSON 导出仍是可携带、可审计的人工备份；服务不可用或本机缓存更新失败时会明确提示。
- 生成或导入内容不会以 HTML 执行，图片链接只接受 HTTPS。
- 不确定的交通、开放时间、拍摄许可和现场状况必须显示为待核实。
- 外部参考图与 OpenStreetMap 底图需要联网；加载失败时路线编号、地点清单、拍摄文字、Checkbox 和署名仍可用。
- 剪映文字状态是 `confirmed-original`；固定正文由用户于 2026-10-17 提供并确认，App 只确定性追加当前项目和手动勾选摘要。

## 目录

- `src/pages/`：项目首页、新建/导入和拍摄页。
- `src/db/`：远程同步、Dexie 缓存、种子项目和备份恢复。
- `worker/`、`db/`、`drizzle/`：私有 Site API、D1 schema 与迁移。
- `src/domain/`：Zod schema、进度、生成指令和剪映文字装配。
- `src/components/shooting/`：复用的成田式拍摄组件。
- `examples/`：成田篇 HTML/JSON 与港未来线计划 JSON。
- `docs/`：实际资产审计和 AI 接入决策。

## 站内 AI 状态

当前未接通。OpenAI 官方网站接入仍是选定合作伙伴的有限试用；当前 Site 没有获批的 OAuth client，也没有完成真实线上模型调用。因此不显示假登录按钮，不使用 AWS 或浏览器令牌存储，也不自动使用开发者付费 API。详见 [`docs/AI_ACCESS_DECISION.md`](./docs/AI_ACCESS_DECISION.md)。

## 尚未承诺的候选能力

PWA 完全离线、外链图片离线、真实照片上传和独立 HTML 导出仍未实现。跨设备同步依赖同一个 ChatGPT/Sites 登录账户和网络；当前没有单独注册账号、邮箱密码或多人共享空间。仍建议定期使用项目 JSON 备份与打印/PDF。
