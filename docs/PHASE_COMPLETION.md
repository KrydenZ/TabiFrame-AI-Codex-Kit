# TabiFrame AI V2 Phase 完成记录

核对日期：2026-10-16。基准：`TABIFRAME_AI_PHASE_PLAN_PROTOTYPE_V2.md`。

## Phase 0 — 资产、部署与 AI 接入验证

- 已审计成田 HTML/JSON、港未来线计划和剪映原文缺口。
- 已确认并部署单一 owner-only ChatGPT Site。
- 已按 OpenAI 官方文档核对远程网站资格；当前未获得远程网站 OAuth/计划调用资格，因此采用外部生成后导入，不做假登录或付费 API 回退。

## Phase 1 — 成田篇拍摄页

- 已保留 5 个时段、38 组、67 条计划素材和 5 张带来源/作者/许可证的参考图片。
- 已完成普通 Checkbox、双重计数、刷新恢复、确认清空、图片失败降级和打印样式。

## Phase 2 — 多项目与个人数据保存

- 已完成项目列表、新建/导入、详情路由和返回流程。
- 项目与进度使用稳定 `projectId + shotId`；按私有 Sites 登录用户 ID 保存到 D1，IndexedDB 作为本机缓存和旧数据迁移来源。
- 按用户追加要求补齐项目查询、资料修改和带确认删除；API 每次请求都按托管身份做所有权隔离。
- 无效记录会隔离并显示恢复建议；保存失败不会静默吞掉。

## Phase 3 — 目的地与结构化拍摄计划

- 已完成最小旅行条件表单、确定性结构化生成指令、粘贴/文件导入和 Zod 严格校验。
- 已强制唯一镜头 ID、合理条数/秒数、HTTPS 链接，以及“已核实事实必须有来源和核实时间”。
- 已用成田和港未来线两类不同内容验证通用渲染；站内生成不可用时继续走外部生成后导入。

## Phase 4 — 剪映文字

- 已实现固定规则草案与受控项目变量装配，勾选摘要只读取当前项目、当前勾选组。
- 状态始终明确为 `rules-draft` / “规则整理草案｜非历史原文”。
- 历史原文尚未取得，因此不声明历史一致性通过。

## Phase 5 — 手机、备份与部署

- 已完成 360px Chrome 视口、触控区、稳定滚动、打印/PDF、项目备份、冲突恢复和单主站私有部署。
